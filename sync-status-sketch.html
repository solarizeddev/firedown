Reality check: Firedown has no cloud sync today — “the vault never leaves the device.” The only existing analogue is the backup mirror (local downloads-mirror.db + AES-GCM public .fdbk + SAF restore). If this is wired to that, the copy should read “Backed up · 2m ago” / “Backing up…” rather than “Synced”, which implies a remote peer that doesn’t exist. “Sync” copy means you’re proposing a new transport — a product decision, not just UI.

The leading slot swaps between a brand-orange spinner (active states — same one the Captured sheet uses for “scanning”) and a single glyph (check / hollow dot / warning). One line, ellipsized. Self-hiding like the subtitle halves: nothing to say → GONE, so a fresh install is just the wordmark. The hairline progress bar is shown only on the uploading variant, and I’d treat even that as optional — the minimal home pushes back on chrome.
