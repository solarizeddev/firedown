Update install — feedback while the APK is handed to Android

Download, patch rebuild and verification all run in the background before the user hears about the update, so nobody waits on them. The one wait is after Install: Firedown copies the ~205 MB APK into Android's installer before Android shows anything. Today the sheet closes on the tap and the screen does nothing for that time. This sketch keeps the sheet up and shows the copy.

Rules

  • The progress replaces the button, in the same footer. No second surface, no layout jump: the footer keeps the button's height.
  • Determinate while copying (we know bytes copied of the file's size), indeterminate once Android has it ("Installing…"), because how long Android takes is not ours to know.
  • The sheet closes when Android answers: its confirmation dialog appears, or the app is closed and replaced. A failure brings the Install button back with one line saying so.
  • One install at a time. A tap on the sheet, the notification and the About row all start the same install; a second tap while one runs does nothing.
  • The notification path gets the same states on the notification itself (the shade is where that user is looking), and the About row says what is happening.
