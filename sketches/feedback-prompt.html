One-time feedback prompt — sketch

A standard snackbar on the Downloads list, shown once ever, the next time the user opens Downloads after their 10th finished download. Tapping the action opens Settings → Send feedback. Dismissing it (swipe, ×, or timeout) retires it for good.

Rules

  • Trigger: the first Downloads open after the 10th FINISHED download (not counting vault files). Counted locally, never sent anywhere.
  • Once ever: showing it sets a pref; it never comes back, whether tapped, swiped or timed out. A user who already sent feedback from Settings never sees it.
  • Never on top of something else: skipped while selection mode, search or another snackbar is up — it simply waits for the next open.
  • Not on the empty list, not in incognito, not in the vault.
  • Copy: one new string pair (message + action) × 16 locales.

Why a snackbar, not a card in the list

  • The top of the Downloads list is already capped at two cards (Safe Folder row + Cloud Backup banner); a third is ruled out.
  • A snackbar is transient and self-clearing, so even an ill-timed one costs the user nothing.
