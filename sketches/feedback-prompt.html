One-time feedback prompt — bottom sheet with illustration

Shown once ever, the first time the user opens Downloads after their 10th finished download. Every option leads to the existing Settings → Send feedback page; dismissing (swipe, scrim tap, Back, "Not now") retires it for good.

Rules (all three)

  • Trigger: the first Downloads open after the 10th FINISHED download (vault files don't count). Counted locally, never sent anywhere.
  • Once ever: showing it sets a pref; any outcome retires it. A user who already sent feedback from Settings never sees it.
  • Never on top of something else: skipped while selection mode, search, another sheet or the restore flow is up — it waits for the next open.
  • Not on the empty list, in a private tab, or in the vault.
  • Copy: title + body + two buttons (B: three row labels) × 16 locales.

Shape

  • Same layout as the existing notifications-priming sheet (the app's other one-time ask): drag handle, 150×126dp illustration, centred title + body, then Not now (text) and a filled Send feedback on the right — the only coral fill.
  • ill_kid is deliberately not offered: it is the buy screen's “something went wrong” face.
  • The quick-topic variant from the last sketch can still sit under the body instead of the single button, if you want it.

Recommendation

  • A (ill_couple) — the only one whose picture says “talk to us” without already meaning something else in the flow the user is in.
