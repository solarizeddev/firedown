Sync & Backup — a simpler split

Two features, one recovery code, but different shapes: bookmarks sync (free, automatic, a toggle) vs. downloads backup (pay-as-you-go, on-demand, a list of files). Forcing them into one parallel settings screen is what reads as clutter. The fix: each overflow opens its own feature screen, and Settings → Sync shrinks to a thin account hub (recovery code + two links).

Settings → Sync = thin account hub
recovery code + 2 feature links + how-it-works

Consistent rule: an overflow always opens that feature’s own screen — never a settings tree. Each feature screen owns its own actions (bookmarks: toggle / sync now / delete · backup: the file list / restore / remove).

Declutters the hub: the confusing Sync now + Delete bookmarks from server move OFF the hub onto the Bookmarks-sync screen where they’re unambiguous.

Free vs paid is explicit: a green FREE pill on bookmarks, a gold PAY AS YOU GO pill on cloud backup — set once on the hub.

Recovery code lives in one place (the hub), with a small link from each feature screen — no more duplicated key rows.
